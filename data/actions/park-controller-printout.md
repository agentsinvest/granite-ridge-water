Ask for the full settings report from the park controller (WeatherTRAK, controller ending 6637). The HOA has only page 3 of 9. Needed:

* Each program, its days, and its start times
* Run time for each station
* The weather adjustment percent for each month
* The winter overseed program
* What the program that runs every night at about 10 PM is

Meter 1 uses about 2,400 gallons a night and meter 2 about 5,500 gallons a night on that 10 PM program (July to September 2026).
