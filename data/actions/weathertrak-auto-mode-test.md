Eco Verde's first recommendation. Both WeatherTRAK controllers (Park and Entrance) are set so the landscaper chooses run times and the controller only scales them for the weather. In automatic mode the controller works out the water from each station's sprinkler type, soil, plants, root depth, sun, and slope.

Eco Verde has seen savings of up to 30% at other sites. That is a best case, not a measured result here, so this is not priced until there is a quote and a test. Controller B (meter 4) is a different make and cannot do this.
