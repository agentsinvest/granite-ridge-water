# /sources

Complete markdown copies of every document Jennifer has shared, so the originals are preserved in git even though `/raw/` is not committed.

* Private repo only. Nothing here is parsed into the app or deployed. The app reads only `/data/`.
* Every file says which original it came from and how it was transcribed and checked.
* Homeowner names and personal ID numbers are redacted. Account and meter numbers appear only as last 4 digits.
* No PDFs. Images are kept only when the image itself is the data (the area map).

| Folder | Contents |
|---|---|
| `pl/<YYYY>.md` | HOA year-end financial reports (balance sheet and statement of revenues and expenses), every line |
| `waterfluence/` | Waterfluence exports (read-period usage, hourly AMI per meter) and a description of the dashboard chart |
| `maps/` | Annotated common-area map and its legend |
| `workbook/` | Jennifer's workbooks: the water model (assumptions, monthly baseline by meter, bill history by meter by year) and the Zone Plan Model (quick wins plan, weather normals, rate notes) |
