# QWEL irrigation audit method

Summary of the form's method, for planning an audit of Granite Ridge zones.

## Before testing

* Only audit a system in good working order; fix and tune first.
* Overhead systems only when wind is 5 mph or less.
* Draw the test area with dimensions, head locations, and catch-can locations.

## Catch-can test

* At least 24 cans, a multiple of four, same size and shape, in a uniform grid about 2 feet from heads.
* Spacing about 5 to 8 feet for fixed and rotary sprays, 10 to 20 feet for rotors.
* Run long enough to collect at least 20 ml: typically 5 to 10 minutes for sprays, 10 to 30 for rotors.
* Catch-can throat areas: Cal Poly / ITRC / DWR 16.25 sq in; Texas A&M 16.61 sq in; Utah State 12.94 sq in.

## Calculations

| Quantity | Formula |
|---|---|
| Low-quarter distribution uniformity (DU_LQ) | average catch of the lowest quarter of cans / average catch of all cans |
| Net precipitation rate, volume in ml (in/hr) | (average volume x 3.66) / (test run time in minutes x can throat area in sq in) |
| Net precipitation rate, depth in inches (in/hr) | (average depth x 60) / test run time in minutes |
| Plant water requirement (in/week) | ETo for one week x plant factor |
| Run time multiplier | 1 / (0.4 + 0.6 x DU_LQ) |
| Irrigation water requirement (in/week) | plant water requirement x run time multiplier |
| Minimum weekly run time (min) | plant water requirement / net precipitation rate x 60 |
| Maximum weekly run time (min) | irrigation water requirement / net precipitation rate x 60 |

## Issues checklist on the form

Mixed hydrozone, needs mulch, high or low pressure, valve malfunction, broken pipes, unmatched precipitation rates, mixed emission devices, no head-to-head coverage, uneven head spacing, excessive overspray, broken or missing nozzles, tilted heads, heads below grade, blocked spray, leaking seals, clogged nozzles, low head drainage, heads not rotating.
